# API Green Score: A Framework to Measure and Reduce the Environmental Impact of Your APIs

*Your APIs are overweight. They transfer megabytes when kilobytes would suffice. It's time to put your APIs on a diet.*

---

## The Problem at a Glance

```
  Client Request: GET /books
         │
         ▼
  ┌──────────────────────────────┐
  │     Naive API (Baseline)     │
  │                              │
  │   Response: 138,327,793 B    │──── 138 MB ──── 🔴 WASTE
  │   Time: 1.24s                │
  │   No pagination              │
  │   No filtering               │
  │   No compression             │
  │   No cache                   │
  └──────────────────────────────┘

         vs.

  ┌──────────────────────────────┐
  │   Green API (Optimized)      │
  │                              │
  │   Response: 974 B            │──── 974 bytes ── 🟢 99.999% LESS
  │   Time: 0.06s                │
  │   ✅ Paginated               │
  │   ✅ Filtered (fields=)      │
  │   ✅ Gzip compressed         │
  │   ✅ ETag cached             │
  └──────────────────────────────┘
```

> *"The way APIs are currently designed contributes to the digital pollution generated by the computer industry, accounting for 4% of greenhouse gas emissions!"* — API Green Score

The [Collectif API Thinking](https://www.collectif-api-thinking.com/) provides an **[evaluation grid (Excel)](https://www.collectif-api-thinking.com/assets/deliverables/worksites/48_CAT_Sustainable_API_GreenScore_V1-2.xlsx)** and a **[best practices guide (PDF)](https://www.collectif-api-thinking.com/assets/deliverables/worksites/50_CAT_API_Sustainable_IT.pdf)**.


### Excel: Strengths and Limits

```
  ✅ STRENGTHS                    ❌ LIMITS
  ────────────────                ────────────────
  Educational                    Snapshot in time
  Forces awareness               Subjective (Yes/No)
  Governance tool                No real measurement
  Easy to share                  No regression detection
  No tooling needed              Doesn't scale (50 APIs × 25 rules)
                                 Outdated after next deploy
```

> The Excel grid answers *"Do we follow the rules?"*
> It doesn't answer *"What is the actual impact right now?"*
